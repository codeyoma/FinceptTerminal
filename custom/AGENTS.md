## Agent skills

### Issue tracker

Work items live in GitHub Issues of the private repo `codeyoma/krx-quant`; always pass `--repo codeyoma/krx-quant` to `gh`. This fork's own issues are automated upstream notices only. See `custom/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `custom/agents/triage-labels.md`.

### Domain docs

Two domains: upstream Fincept (`docs/ARCHITECTURE.md`, `docs/adr/`) and the krx-quant engine (`../krx-quant/docs/design.md`), plus fork rules in `custom/README.md`. See `custom/agents/domain.md`.
